# Unsupervised Learning - Clustering

This project contains Python implementations of unsupervised learning algorithms, specifically focusing on **K-means Clustering** and centroid initialization techniques using `numpy` and `tensorflow` (where applicable).

## Tasks
* **0. Initialize K-means**: Initialize cluster centroids for K-means using a multivariate uniform distribution.
