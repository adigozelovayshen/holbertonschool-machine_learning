# Supervised Learning - Object Detection (YOLO v3)

## Description
This repository contains projects focused on **Object Detection** using the **YOLO v3 (You Only Look Once)** algorithm implemented in TensorFlow / Keras.

## Requirements
* Python 3.x
* TensorFlow 2.x
* NumPy
* OpenCV

## Files & Tasks

| File | Description |
| --- | --- |
| `0-yolo.py` | Contains the `Yolo` class that initializes a pre-trained Darknet Keras model for object detection along with class names, score thresholds (`class_t`), Non-Max Suppression thresholds (`nms_t`), and anchor boxes. |
