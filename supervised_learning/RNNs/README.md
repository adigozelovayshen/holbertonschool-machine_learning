# Recurrent Neural Networks (RNNs)

This directory contains projects and exercises related to Recurrent Neural Networks (RNNs), Gated Recurrent Units (GRUs), Long Short-Term Memory networks (LSTMs), Deep RNNs, and Bidirectional RNNs implemented in Python and NumPy.

## Files

* `0-rnn_cell.py`: Python class `RNNCell` that represents a single cell of a simple Recurrent Neural Network (RNN).
