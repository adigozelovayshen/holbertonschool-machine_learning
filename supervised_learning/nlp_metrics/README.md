# Natural Language Processing - NLP Metrics

This project focuses on understanding and implementing evaluation metrics used in Natural Language Processing (NLP), such as BLEU and ROUGE scores, to assess the quality of machine-generated text compared to reference human translations.

## Requirements

- Python 3.8+
- `nltk` library
- `pycodestyle` (version 2.5.0)

## Tasks

| File | Description |
| --- | --- |
| `0-uni_bleu.py` | Calculates the unigram BLEU score for a sentence. |
| `1-ngram_bleu.py` | Calculates the n-gram BLEU score for a sentence. |
| `2-cumulative_bleu.py` | Calculates the cumulative n-gram BLEU score for a sentence. |
