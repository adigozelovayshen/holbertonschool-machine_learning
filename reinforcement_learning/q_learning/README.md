# Q-Learning

## Description
This directory contains project tasks for understanding and implementing the Q-Learning algorithm using Open AI Gymnasium's `FrozenLake-v1` environment.

## Tasks
* **0-load_env.py**: Function `load_frozen_lake(desc=None, map_name=None, is_slippery=False)` that loads the pre-made FrozenLakeEnv environment from gymnasium.

## Requirements
* Python 3.x
* Gymnasium
* Numpy
